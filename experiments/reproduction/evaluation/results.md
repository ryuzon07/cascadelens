# Published baselines: evaluation run

Generated by `cascadelens published evaluate`. Unsupervised methods, on the same splits, windows and cases as `experiments/baselines_clean`. Scores are percentages with 95% group-bootstrap intervals, averaged per case over each method's seeds.

`baro` sees every metric, like the other baselines, and splits normal from anomalous at 25% of the window, computed without `inject_time`. `lingam_randomwalk` uses no anomaly time, and runs on a smaller key metric set because all metrics are infeasible for it, which departs from identical inputs. `baro_key_metrics` is BARO on that same set, for a fair comparison. `baro_midpoint` splits at 50%, which sits next to the true injection in nearly every case, so it is a **sensitivity check for the window-leak probe and not a fair score**.
