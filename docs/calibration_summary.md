# Calibration summary

Generated by `cascadelens experiments calibration`. **Status: exploratory.**

The config is not frozen, so verdicts below preview the pre-registered tests.

The CascadeLens ranker is `ranker_augmented`. Each fold's calibrator and tau come from that fold's validation cases, pooled across seeds. They are not pooled across folds, because validation cases of one fold are test cases of another. Validation also steered the ranker's early stopping and search, so it may look better than test. Nothing was refitted on perturbed data.

Rows of all seeds are stacked and groups are resampled. ECE is always shown with its interval, and the reliability diagrams are in `experiments/calibration/figures/`. Random abstention's expected accuracy equals full-coverage accuracy, so one difference answers both S4 comparisons.

## Caveats

- ECE before uses a softmax at temperature 1, but ranking scores have no natural scale, so the before value is partly arbitrary and S5 is an easy bar.
- Stacking seeds averages their errors, so stacked ECE sits below the mean ECE of single seeds; `seed_spread` in the results has that value.
- Confidence is compared across folds that have different calibrators.
- A zero-width interval means one tied block of confidences covers that coverage.
- Folds whose validation predictions were all correct give the calibrator no errors to learn from, so confidence saturates: loso fold 2.
